# 伤病与可用性测试政策

> 本文是 FCRecruiter 的合成 RAG 测试语料，不构成医疗建议，也不代表真实俱乐部标准。

## 评估原则

伤病风险不能只统计受伤次数，还要区分伤病部位、复发模式、缺席天数、比赛负荷和复出后的使用情况。同一部位重复受伤通常比多次轻微且无关联的伤病更值得复核。

## 测试分级

本测试语料使用虚构的“可用性灯号”：过去十二个月累计缺席不超过十天为绿色，十一至三十天为琥珀色，超过三十天为红色。灯号只用于测试检索，不应直接用于真实医疗决策。

## 招募影响

高风险不等于自动否决。球队需要结合目标角色负荷、替补深度、合同成本和医疗评估决定是否承担风险。要求大量重复冲刺的角色，对下肢复发记录应更加谨慎。

## Evidence 边界

Agent 应明确区分已记录的缺席事实与对未来伤病的推断。没有医疗检查结果时，不应判断具体病理原因，也不能把公开缺席记录解释为确定的长期风险。
