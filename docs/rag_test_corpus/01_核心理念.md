# 阿尔特塔核心执教理念

## 控制比赛

控制不只是控球率，而是控制球的位置、队友间距、丢球后的局面和对手的推进出口。球员需要提前扫描、维持结构，并在压力下做低风险但不保守的选择。

**招募含义**：重视比赛理解、受压决策和位置纪律，不只看技术集锦。

## 原则稳定，阵型可变

4-3-3、4-2-3-1、3-2-4-1只是阶段性结构。稳定原则是：后场创造出球优势，占据宽度和肋部，让关键球员在两线间接球，并保留防守保护。

**招募含义**：多面手必须真正理解多个角色，而不只是踢过多个位置。

## 主动性与适应性

球队希望主动规定对手向哪里出球，并通过高压、反抢和高位防线维持压制。但面对不同对手，也能使用直接球、低位防守和转换进攻。

**招募含义**：球员要能在不同节奏、结构和比赛状态下解决问题。

## 文化与人格

阿尔特塔强调纪律、责任、日常标准和适合团队文化的人格。理想球员在困难时仍愿意要球、执行任务、帮助队友，并能接受直接反馈。

**招募含义**：核查替补、失误、伤病和角色变化后的真实行为。
