# 低位防守体系测试手册

> 本文是 FCRecruiter 的合成 RAG 测试语料，不代表真实俱乐部内部标准。

## 体系目标

低位防守优先压缩禁区前沿、肋部和中央通道，允许对手在远离球门的区域横向传递。球队通常维持两条紧凑防线，通过人数密度降低对手在危险区域转身和直塞的机会。

## 防守优先级

第一优先级是保护禁区弧顶附近的中央区域，第二优先级是防守后点，第三优先级是争夺解围后的第二落点。边路持球本身不是立即出击的理由，只有当对手失去向内连接或准备传中时，外侧球员才应主动施压。

## 招募要求

中后卫重点评估禁区站位、头球解围、封堵和连续处理传中的稳定性；中场需要保持纪律、保护中路并争夺第二点；边锋也必须回到球后协助边后卫。回追速度有价值，但不像高位防线那样构成首要门槛。

## 主要风险

长期低位防守会让球队难以向前推进，并增加连续防守造成的失误概率。只会解围而不能帮助球队离开压力的球员，可能使球队反复丢失球权。因此，至少需要一名能够护球或完成第一脚向前传递的出口球员。
