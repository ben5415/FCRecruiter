# 防守型后腰招募画像

> 本文是 FCRecruiter 的合成 RAG 测试语料，不代表真实俱乐部内部标准。

## 角色任务

防守型后腰的首要职责是保护中后卫身前区域，限制对手在中央和肋部转身，并在边后卫前插后填补留下的空间。他可以把简单出球交给身旁的组织者。

## 核心能力

重点观察防守站位、拦截预判、身体对抗、覆盖范围、犯规控制和第二落点处理。抢断次数需要结合球队防守方式解释：位置错误后进行的补救抢断，不一定优于提前封锁线路。

## 持球要求

球员应能完成安全的短传和压力下的基本护球，但不要求持续承担推进创造。接球后快速找到组织核心，比自己尝试高风险直塞更符合角色分工。

## 与组织型六号位的区别

防守型后腰以破坏和保护为主要价值，组织型六号位则负责连接和控制节奏。部分球员可以兼具两者，但不能因为位置名称相同就假设能力可以互换。
