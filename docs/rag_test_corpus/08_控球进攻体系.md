# 控球进攻体系测试手册

> 本文是 FCRecruiter 的合成 RAG 测试语料，不代表真实俱乐部内部标准。

## 体系目标

控球进攻的目标是通过站位和传递移动对手，创造自由人及更高质量的推进线路。控球率只是结果之一，真正需要关注的是球队能否稳定占据宽度、肋部和中央区域，并在丢球前保留防守保护。

## 位置原则

持球侧需要形成至少三个不同高度的接应点，弱侧球员保持宽度准备接收转移。两名球员不应长期占据同一条传球线。中场接球前需要扫描，并尽量以开放身体姿态连接下一方向。

## 招募要求

球员需要在狭小空间内完成连续处理，理解何时保持位置、何时交换区域。传球成功率不能脱离传球方向和压力环境评价。只进行安全横传、却无法吸引或突破防线的球员，不一定适合位置进攻。

## 主要风险

控球体系可能出现节奏缓慢和无效传递。球队需要兼具耐心与突然加速的能力，并在持球结构中保留足够人员应对反击。技术能力较好但位置纪律不足的球员，可能破坏整体空间。
