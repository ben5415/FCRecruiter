# 内收边后卫招募画像

> 本文是 FCRecruiter 的合成 RAG 测试语料，不代表真实俱乐部内部标准。

## 角色任务

内收边后卫在球队控球时离开传统边线区域，进入后腰或中场位置，帮助球队形成中路人数优势。他需要根据球的位置判断何时进入中场、何时回到边路，以及何时成为后场第三名防守者。

## 核心能力

重点评估接球前扫描、背身接球、半转身、短距离传递、空间意识和丢球后的反应。球员即使拥有边后卫经历，如果无法在中路承受来自多个方向的压力，也不应被认定为合格的内收边后卫。

## 防守要求

内收后形成的防守位置可能与传统边后卫不同。球员需要保护中路、争夺第二落点，并在球权转移后及时回到外侧处理边锋。判断速度比单纯冲刺速度更重要。

## 主要风险

频繁内收可能让本方边路短暂暴露，因此边锋、中卫和后腰必须理解轮转关系。候选球员如果习惯始终贴住边线，或接球后只能面向边线推进，需要较长适应期。
