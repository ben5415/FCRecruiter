# 出球型中后卫招募画像

> 本文是 FCRecruiter 的合成 RAG 测试语料，不代表真实俱乐部内部标准。

## 角色任务

出球型中后卫不仅要把球传给最近的队友，还要通过持球和传球改变对手的压迫结构。他需要判断何时吸引前锋、何时找到中场自由人，以及何时直接向边路或锋线完成越线传球。

## 核心能力

重点观察接球前扫描、第一脚触球方向、受压时的身体姿态、弱脚安全性、持球推进和中距离传球。传球次数多并不等于出球能力强，应区分无压力横传与真正突破压迫的传球。

## 防守要求

技术能力不能替代防守能力。角色仍需要保持防线距离、主动前顶、处理身后空间，并在丢球后快速调整站位。高位体系尤其重视大空间一对一和回追判断。

## 否决条件

如果球员在被逼向弱脚时频繁仓促解围，或必须依赖后腰回撤到极深位置才能完成推进，应降低适配评价。低位解围数据很高，但缺少受压出球样本，也不足以证明其适合该角色。
