# 快速反击体系测试手册

> 本文是 FCRecruiter 的合成 RAG 测试语料，不代表真实俱乐部内部标准。

## 体系目标

快速反击强调在夺回球权后利用对手结构尚未恢复的阶段向前推进。第一脚处理应优先寻找可以转身的中场、边路空当或前锋身后跑动，而不是为了速度盲目长传。

## 测试规则

本测试体系把夺回球权后的前八秒定义为“快速窗口”。在这段时间内，至少一名球员提供纵向跑动，另一名球员提供安全接应。如果向前线路被封闭，球队应保留球权，而不是强制完成低成功率传球。

## 招募要求

前锋需要启动速度、跑动时机和高速下的终结能力；边锋需要能够带球推进并在冲刺后继续作出判断；中场需要抬头速度和第一时间向前传球能力。只擅长静态控球、需要多次触球才能观察的球员，可能减慢转换。

## 主要风险

反击体系不能只依赖速度。缺少接应层次会让持球者陷入孤立，过早向前传球也会迅速归还球权。评估候选时应同时检查无球跑动、推进后的决策和丢球后的回防意愿。
