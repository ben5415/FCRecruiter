# 组织型六号位招募画像

> 本文是 FCRecruiter 的合成 RAG 测试语料，不代表真实俱乐部内部标准。

## 角色任务

组织型六号位连接后场与前场，在中卫身前提供稳定接应，并通过转身、少触球传递和节奏变化帮助球队越过第一线压迫。他需要持续调整站位，为持球者打开安全但具有推进价值的线路。

## 核心能力

重点评估扫描频率、开放身体姿态、受压护球、弱侧转移、越线传球和比赛节奏控制。高传球成功率只有在球员经常面对压力并尝试向前连接时才具有充分意义。

## 防守要求

该角色需要保护中路、判断第二落点并延缓反击，但不一定依靠大量抢断体现价值。提前站位和封锁线路可以减少进入直接对抗的次数，因此不能只用抢断总数评价防守贡献。

## 否决条件

接球前缺少观察、只能回传给中卫、被贴身后频繁丢球，都是严重风险。具备长传能力但无法在狭小区域完成第一脚处理，也不足以承担单后腰组织职责。
