# 身后冲击型中锋招募画像

> 本文是 FCRecruiter 的合成 RAG 测试语料，不代表真实俱乐部内部标准。

## 角色任务

身后冲击型中锋通过纵向跑动迫使防线后退，在转换和较大空间中制造直接威胁。他需要识别传球队员抬头、后卫视线转移和防线移动不同步的瞬间启动。

## 核心能力

重点观察启动时机、前几步加速、弧线跑动、越位控制、高速带球和单刀终结。最高速度并不能代替跑动判断，频繁提前启动造成越位会降低进攻连续性。

## 有球要求

这类球员可以减少复杂背身任务，但仍需完成基本做墙和压力下护球，否则在对手低位防守时容易与球队脱节。面对深度很小的防线时，应能够通过横向移动和禁区跑位继续贡献。

## 主要风险

如果球队很少获得转换空间，纯速度优势可能难以发挥。招募前需要判断球队能否稳定提供身后传球，以及候选在阵地战中的替代作用。
