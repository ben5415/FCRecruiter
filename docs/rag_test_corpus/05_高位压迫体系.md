# 高位压迫体系测试手册

> 本文是 FCRecruiter 的合成 RAG 测试语料，不代表真实俱乐部内部标准。

## 体系目标

高位压迫的目标不是让所有球员同时向前奔跑，而是通过第一线的跑动角度封锁中路，把对手引导至预设边路，再由边锋、中场和边后卫形成局部包围。后卫线必须同步前移，缩短前中后三线距离。

## 压迫触发

测试体系规定三类主要触发信号：对手回传门将、接球队员身体朝向本方球门、以及停球明显离开身体。第一名压迫者负责封锁回传或向内线路，第二名球员接管近端接应点，而不是两人同时扑向持球者。

## 招募要求

前锋需要理解封线角度和连续压迫；中场需要快速前顶并保护身后；中后卫需要主动压缩空间、处理大范围一对一和身后球。单纯拥有高体能但缺少启动时机的球员，不应被视为优秀的高压球员。

## 主要风险

如果第一线压迫被轻易绕过，高位防线会暴露大片身后空间。因此，速度只是基础，门将出击、后卫预判和全队同步程度同样重要。无法保持紧凑距离的阵容不适合持续执行高位压迫。
